Run the demo locally

Download the self-contained demo. Node 22.18 or newer is required; the offline example needs no API key or dependency installation.

Download the demo ↓ 
tar -xzf wompar-demo.tar.gz
cd wompar-demo
node demo/wompar/wompar.mjs --offline

To run a fresh comparison or generation, add one supported provider key on your own computer. Provider charges may apply.

The saved example compares one source view; it is not a global ranking. A full WOMPar score requires the complete frozen course and the prescribed judging evidence.
